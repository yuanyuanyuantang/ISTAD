# SWAT 宽度试点预注册（prereg_swat_width.md，2026-09-02，训练启动前落盘）

**性质：预测性预注册（训练启动前锁定旋钮与判据）。**

## 背景与动机

v2.1 收官后用户决策打 SWAT 容量试点（在"收官 / SWAT grid 试点 / SWAT 加宽试点"三选项中
选定加宽）。已向用户完整披露证据：C/D 表诚实赢家为最小容量模型（KANAD 9.8k / DLinear 20k）、
容量↑ 对 C 的机制方向偏负（对漂移特征重建更好 → 正常重尾更高 → POT 阈值更高）、
历史容量线全灭或已收割（grid5→10 已用、lr 扫描全灭、HGST v2 FAIL、双头三数据集预注册否决）。
本试点是**低先验概率、用户授权**的最后一条容量线；无论结果如何均如实入表。

## 旋钮（唯一改动）

`--istad_kernel_size` 15 → 25（KAN-TCN 卷积核/时间宽度；其余全部不动）。

- 参数量（CPU 构建 `models.ISTAD.Model` 实测）：k15 = 303,330（与论文逐位一致，配置重建
  可信）→ **k25 = 329,340（+26,010，×1.09）**。
- 其余超参忠实复刻 SWAT g10 配方（bs128 双卡、lr0.001、cosine、30 epochs、patience10、
  g10、order6、256-wide（gat/gru/recon）、n_hyperedges20、k_top10、dropout0.1、sl96）。
- **不开** `--istad_revin` / `--istad_dual`（判定对象 = 现行采纳配置的加宽版）。
- `--istad_enable_explain 0`（与 dual/revin 模板一致；不影响训练/分数，仅省时）。
- 种子：48 / 89 / 2021（3 种子，与 SWAT 统一表口径一致）；`--des SWAT_k25_s{seed}`。

## 评估管线（现在锁定）

1. dump：`dump_istad_perfeat.py` 新增 MODE='k25'（base 前向 + kernel_size=25 覆写 +
   CKPT 硬断言显式键 + 落盘 `{DS}_s{seed}_k25.npz`，禁止静默回退 k15 权重）；
   DUMP_BS['SWAT']=32（k15 已实测训练侧测试 OOM；k25 更重，如仍 OOM 只降 dump 批，
   训练批不动）。
2. 打分：gated 聚合（`final_matrix.gated_score`，逐特征训练误差 p99.9 门控）——
   与现行 SWAT 采纳行完全同族，仅换 checkpoint。
3. 协议：A=POT+raw（SPOT q=1e-5，lm SWAT=(0.9999,1.2)）；B=AP/ROC；C=POT+PA；
   D=bf+PA（两段式 200+500 + PA，离线复刻 bf_search_adaptive）。
   阈值/搜索/PA 实现与 unified 表逐位同源（final_matrix.py 复用）。

## 判定（3 种子 mean±std，ddof=0；门槛作用在 mean 上；四条全过才采纳）

| # | 指标 | 门槛 | 参照 | 含义 |
|---|---|---|---|---|
| 1 | D (bf+PA) | **≥ 0.8764** | DLinear 诚实参照 0.8764 | 必须超诚实 SOTA，打平不算 |
| 2 | AP | ≥ 0.73 | gated 现行 0.7317 | 护栏：不显著回退 |
| 3 | ROC | ≥ 0.84 | gated 现行 0.8413 | 护栏：不显著回退 |
| 4 | C (POT+PA) | ≥ 0.8075 | gated 现行 0.8125−0.005 | 护栏：保护 SWAT C 诚实第一（启动前追加，较用户批准的三条更严）|

A（POT+raw）不设判据（牺牲叙事，如实记录）。

## 决策规则

- **四条全过 → ADOPT**：SWAT 最终行换 k25 gated（五表刷新；效率表加注 SWAT 329,340；
  消融等网格口径不受影响——k25 仅主表，或全消融补跑，届时另行决策并如实写）。
- **任一不过 → KEEP k15**：v2.1 维持原样；k25 三种子结果全部如实写入素材作负结果存档。
- **禁止事后变体切换**：k25 上的 min_z / trim1 / dual 等任何其它打分或训练变体只作
  side observation 记录，不构成本预注册下的采纳理由；若要采纳须新预注册。
- 三种子必须全部训练并全部报告（不看中期结果删种子）；单种子 pilot 不设
  （SWAT 种子方差大，单种子不可信——历史教训）。

## 判定结果（2026-09-02，swat_k25_tables.log）

k15 回归校验 5/5 逐位复现现行采纳行（D 0.8689 / C 0.8125 / ROC 0.8413 / AP 0.7317 /
A 0.2583）——管线精确。3 种子 mean±std（ddof=0）：

| 指标 | k25 | k15 | 门槛 | 结果 |
|---|---|---|---|---|
| D | 0.8692±0.0094 | 0.8689±0.0034 | ≥0.8764 | **✗** |
| AP | 0.7367±0.0040 | 0.7317±0.0048 | ≥0.73 | ✓ |
| ROC | 0.8415±0.0046 | 0.8413±0.0081 | ≥0.84 | ✓ |
| C | 0.8149±0.0081 | 0.8125±0.0054 | ≥0.8075 | ✓ |
| A | 0.2581±0.3580 | 0.2583±0.3516 | 不设 | — |

**判定：KEEP k15（v2.1 维持）。** k25 全指标与 k15 差异在噪声内（Δ ≤ +0.005），
×1.09 容量增量对 SWAT 全部 PA 族指标惰性——与预分析（PA 口径非容量门控）一致。

**机制副产物（A 表素材）**：POT 过冲是"标定×种子"交互而非模型属性——k25 把过冲种子
从 {48,2021} 换成了 {89,2021}（s48 A 0.0127→0.7645、s89 0.7554→0.0026），均值/方差不变。
同族加宽模型换种子即翻转过冲，直接证明 A 列失败源于 EVT 阈值对种子分数分布漂移的脆弱性，
表征无关。
