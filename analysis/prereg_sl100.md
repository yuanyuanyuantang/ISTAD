# seq_len 试点预注册（prereg_sl100.md，2026-09-02，训练启动前落盘）

**性质：预测性预注册。** 用户在"收官 / seq_len 试点 / λ 扫描 / 都打"中选定"两个都打（seq_len 先）"。

## 动机与唯一改动

`--seq_len` 是唯一存在文档级基线错配的超参轴（素材 §3.3.5 窗口 caveat）：
PSM 基线 TimesNet/DLinear 用 sl100（KANAD sl64），SWAT 基线 sl100（KANAD sl80），
ISTAD 现行 PSM sl64 / SWAT sl96。机制先验：更长窗口→每分数点更多上下文→段级 touching
上升→PA 段填充（C/D 直指）。注：事后分数平滑已证伪，但"训练在长窗口上"是不同机制，
以实测裁决。**其余一切超参与架构不动**（kernel 保持 15、g10、dual λ 保持 1.0）。

- PSM：dual 联合训练 sl64→**sl100**（4 种子 87/90/98/2021；`--des PSM_g10_dual_sl100_s{seed}`，
  忠实复刻 PSM dual 配方：单卡 bs64、lr0.01、3ep、patience5）。
- SWAT：gated 配置 sl96→**sl100**（3 种子 48/89/2021；`--des SWAT_sl100_s{seed}`，
  忠实复刻 SWAT g10 配方：双卡 bs128、lr0.001 cosine、30ep patience10，不开 revin/dual）。

## 评估管线（锁定）

dump：`dump_istad_perfeat.py` 新增 MODE='dual_sl100'（PSM，dual 前向 + seq_len=100 覆写）
与 MODE='sl100'（SWAT，base 前向 + seq_len=100 覆写）；CKPT 显式键 + 硬断言；
落盘 `{DS}_s{seed}_{MODE}.npz`；label 取 base 文件按 `n_win*W` 截断（sl100 平铺长度）。
打分：PSM = dual min_z（min(z(gated_base), z(mean_revin))，与现行采纳同族）；
SWAT = gated。协议 = final_matrix 同源（POT lm、bf_pa 两段式 + PA、AP/ROC）。

## 判定门槛（mean，ddof=0；全部满足才采纳）

**PSM**（4 种子，现行参照：C 0.9564±0.0086 / D 0.9696±0.0105 / ROC 0.7462±0.0211 /
AP 0.4874±0.0222）：
- 主门槛（**二选一**即算超 SOTA）：C ≥ **0.9673**（TimesNet 0.9672）**或** D ≥ **0.9733**（TimesNet 0.9732）
- 护栏：ROC ≥ 0.7412（ref−0.005）、AP ≥ 0.4824（ref−0.005）
- A 不设判据

**SWAT**（3 种子，与 k25 预注册同门槛集，现行 gated 参照：D 0.8689 / C 0.8125 /
AP 0.7317 / ROC 0.8413）：
- D ≥ 0.8764（DLinear 诚实参照）且 C ≥ 0.8075 且 AP ≥ 0.73 且 ROC ≥ 0.84

## 决策规则

- 全过 → ADOPT sl100（该数据集最终配置更换，五表刷新；窗口 caveat 脚注同步消掉）。
- 任一不过 → KEEP 现行 sl，**seq_len 轴关闭**，结果如实入素材作负结果。
- 禁止事后换打分变体或种子；三/四种子全训全报。
- 单种子 pilot 不设（SWAT 种子方差大、PSM 已有 4 种子方差证据）。

## Wave 2 依赖声明（dual λ 扫描，prereg_psm_lambda.md）

λ∈{0.5,2.0} 扫描的**基线配置 = Wave 1 判定后的 PSM 最终 sl 配置**（sl64 或 sl100），
避免轴间交互；选择准则 = 验证集 bf-F1（无测试泄漏），测试集只评入选 λ 一次。

## Wave 1 判定结果（2026-09-03，sl100_tables.py / swat_verdict.log）

**SWAT：KEEP sl96（seq_len 轴关闭）。** sl96 回归校验 5/5 逐位复现现行采纳行（管线精确）。
3 种子 mean±std（ddof=0）：

| 指标 | sl100 | sl96 | 门槛 | 结果 |
|---|---|---|---|---|
| D | 0.8694±0.0167 | 0.8689±0.0034 | ≥0.8764 | **✗** |
| C | 0.8133±0.0057 | 0.8125±0.0054 | ≥0.8075 | ✓ |
| AP | 0.7332±0.0053 | 0.7317±0.0048 | ≥0.73 | ✓ |
| ROC | 0.8393±0.0043 | 0.8413±0.0081 | ≥0.84 | **✗** |
| A | 0.5033±0.3482 | 0.2583±0.3516 | 不设 | — |

sl100 全指标与 sl96 噪声内持平（|Δ| ≤ 0.005，D 方差更大）——与 k25 宽度试点同一结论：
SWAT 的 PA 族指标对"每分数点上下文 +4"惰性，机制先验（更长窗口→更多上下文→段级
touching↑）在 SWAT 不成立（其异常段本身长，sl96 已饱和覆盖）。
**A 侧副产物（复证 k25 机制发现）**：POT 过冲种子再次轮换——sl100 下过冲种子变为
{2021}（s2021 A 0.0109 vs s48/s89 0.743/0.756），再次证明 A 列失败 = "标定×种子"交互，
表征无关。

## Wave 1 判定结果·PSM 轨（2026-09-03，sl100_tables.py）

**PSM：KEEP sl64（seq_len 轴两数据集全部关闭）。** sl64 回归校验 5/5 逐位复现现行采纳行（管线精确）。
4 种子 mean±std（ddof=0）：

| 指标 | sl100 | sl64 | 门槛 | 结果 |
|---|---|---|---|---|
| D | 0.9869±0.0026 | 0.9696±0.0105 | ≥0.9733（二选一） | **✓** |
| C | 0.9443±0.0227 | 0.9564±0.0086 | ≥0.9673（二选一） | ✗ |
| ROC | 0.7086±0.0267 | 0.7462±0.0211 | ≥0.7412（护栏） | **✗** |
| AP | 0.4607±0.0148 | 0.4874±0.0222 | ≥0.4824（护栏） | **✗** |
| A | 0.0164±0.0046 | 0.0996±0.0557 | 不设 | — |

主门槛按"或"分支（D）确实达标——sl100 下 D +1.73pp（0.9696→0.9869，名义超 TimesNet
0.9732），机制先验（更长窗口→每分数点上下文↑→段级 touching↑→PA 填充）在 PSM 的 PA 族
指标上**成立**（与 SWAT 的惰性形成对照）。但代价是裸分数质量全面下滑：ROC −3.8pp、
AP −2.7pp，两条护栏同时击穿——正是预注册护栏要防的"PA 虚胖、排序变差"形态。
按决策规则任一不过 → **KEEP sl64，PSM seq_len 轴关闭，负结果如实入素材**。

**A 侧副产物**：sl100 下 POT 过冲种子轮换再现——4 种子 A 全部 ≤0.024（s87 0.0235 /
s90 0.0169 / s98 0.0148 / s2021 0.0106），过冲从"个别种子"变为"全种子"，与 k25 一致：
A 列失败 = "标定×种子（×窗口）"交互，表征无关。

**Wave 2 依赖解除**：λ 扫描基线配置锁定 = **sl64**（现行配置不变，λ∈{0.5,2.0} 直接可跑）。
